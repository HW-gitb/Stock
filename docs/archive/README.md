# Archive

This directory stores historical source material. It is not part of the active LLM reading path.

## Rules

- Do not use archived `.docx` files as current execution, schema, or strategy authority.
- Current A-short reference material lives under `skills/a_short_analysis/reference/`.
- Current US-short reference material lives under `skills/us_short_analysis/reference/`.
- Current production-facing strategy specs live under `docs/` and are routed by `docs/README.md`.
- Open archived files only for source archaeology or when a task explicitly asks for old framework comparison.
- Do not delete archived user-provided source material without explicit user approval.

## Contents

- `a_short_analysis_old_versions/` — old A-share framework `.docx` versions.
- `us_short_analysis_old_versions/` — old US-share framework `.docx` versions.
