# EGS v7.4 全市场量化版（三补丁融合·Tushare 深度加固·预期差分布修复·参数对齐）

> **定位**：面向全 A 股主板（不含创业板、科创板、北交所）的周频量化多因子筛选框架。  
> **核心升级**：v7.3 基础上完成与生产脚本的参数对齐——top_n 适配、分散度百分比化、冗余硬截断规则保留为安全网。

## L1 行业景气预筛（两项评分，政策方向后移）

| # | 条件 | 量化标准 |
|---|------|----------|
| ① | 毛利率趋势 | 若有近两季行业加权毛利率 YoY：均 > 0 → 1 分；一扩一收 → 0.5 分；均收 → 0 分。**缺失 → 0.5 分（免检）** |
| ② | 龙头涨幅 | 行业主板市值前 3 或近 20 日涨幅前 2，且 5 日均成交 > 1 亿 → 20 日涨幅 ≥ 沪深 300 + 2% → 1 分；无合格龙头 → 免检（0.5 分） |

**行业政策风险推迟至第三级漏斗（AI 联网清算）统一审查。**

**处理**：
- 2 分 → 通过
- 1.5 分 → L5 扣 15 分，标记 `ITF-2`
- 1 分 → 淘汰
- 0.5 分 → 淘汰
- 龙头涨幅 < 沪深 300，且回调 < 15%，行业 PE 近 3 年分位 < 50% → L5 扣 10 分，标记 `ITF-ADJ`（不影响通过/淘汰）
- 行业排除后主板可交易 < 5 只，且 L1 总分为 1.5 分 → L5 扣 10 分，标记 `ITF-ADJ`

## L2 预期差识别（融合补丁一 & 补丁三，v7.3 分布修复）

### 1. 盈利预期差（修正版，含去极值处理及双侧分布修复）

**核心指标**：个股最新单季度扣非净利润同比增速 vs 申万同行业扣非净利润同比增速中位数。

```
预期差比值 = 个股增速 ÷ 行业中位数增速
```

**超预期判定规则**：

| 行业中位数状态 | 超预期条件 |
|---------------|------------|
| 中位数增速 > 0 | 比值 > 1.5 |
| 中位数增速 ∈ [-3%, 0) | 个股增速 > 0 **且** > 5% |
| 中位数增速 < -3% | 个股增速 > 0 **且** > | 行业中位数增速 | |
| 中位数增速 ≤ 0 且个股增速 ≤ 0 | 直接不通过 |

**连续两季要求**：
- 最近两个单季度**均满足**上述超预期条件 → 有效超预期
- 仅最新季度满足 → 标记 `ESP-Q`，最终分 × 0.7

**原始预期差分值**（用于 L5 标准化，双侧分布）：

| 情形 | 公式 |
|------|------|
| 有效超预期（连续两季） | `原始值 = \|行业中位数增速\| + (个股增速 - 行业中位数增速)` |
| 有效超预期（仅最新季度，ESP-Q） | `原始值 = \|行业中位数增速\| + (个股增速 - 行业中位数增速)` |
| 行业中位数 ≤ 0 且个股增速 ≤ 0 | `原始值 = 个股增速 × 0.5`（可为负） |
| 未超预期（行业中位数 > 0） | `原始值 = 个股增速 - 行业中位数增速`（可为负） |
| 数据缺失（DATA-INC） | `原始值 = 0` |

**补丁一 · Winsorization 去极值**：
在全市场计算 Z-Score 前，对"预期差原始值"序列进行 **前后 1% 的极值剪裁（Winsorize）**，替换为第 1 和第 99 百分位的值。

**补丁三 · 缺失值容错**：
- 单季增速或行业中位数缺失 → 原始预期差分 = 0，超预期标记 False，并追加标记 `DATA-INC`
- 行业中位数缺失 → 强制标记 `COV-LOW`，标准化得分上限锁定 1.0（即预期差得分 50）

### 2. 质量验证
- 近 12 个月非经常性损益 / 净利润 < 20%（由净利润与扣非净利润反推）
- 经营性现金流 / 净利润 > 0.7（净利润在 ±100 万以内时仅需现金流 > 0）  
  数据源：`cashflow` 接口，缺失则本条件跳过，标记 `ESP-Q`
- 净利润或扣非净利润任一缺失 → 标记 `ESP-Q`，质量验证跳过
- 任一条件不满足 → `ESP-Q`，最终分 × 0.7

### 3. 估值预期差
- PE 处于行业后 30% 且 ROE 处于行业前 30% → +10 分；PB < 1 且 ROE > 10% → +10 分（上限 20）  
- PE > 行业均值 ×2 且 PEG > 1.5，或处于 52 周高点 5% 以内且 PE > 行业均值 ×2 → −10 分  
- PE > 行业均值 ×3 且 PEG > 2 → −15 分（标记 `VAL-X`）  
- PE / PB / ROE 缺失 → 估值项跳过（不加不扣）
- PEG 缺失 → PEG 相关条件跳过

### 4. 资金预期差
- **淘汰**：近 10 日大股东减持 = 1；近 5 日内单日跌幅 > 5% 且收于日内最低 20% 区间，且次日开盘 30 分钟未收复该日跌幅一半；近 10 日融资余额增幅 > 15% 且股价涨幅 < 3%（若近 5 日均量 < 20 日均量 ×0.8 可豁免）  
  融资余额数据由 `margin` 接口提供，缺失则融资条件跳过
- **扣 10 分**：10~30 日内有减持公告  
- 过去 3 月调研次数 ≥ 10 → −10 分（标记 `OVER`）—— **因 Tushare 无数据，本条永久冻结，不扣分不标记**  
- L4 动量三要素满分可豁免"调研过度"扣分（若启用）

### 5. 一票否决（直接淘汰）
- 同时满足 `ESP-Q` 且 PE > 行业均值 ×3 且 PEG > 2  
- 近 10 日大股东减持 = 1  
- 近 5 日内单日跌幅异常且未收复

## L3 催化剂时间表（含冷启动备援）

### 催化剂强度计算
- **A 档（主方案）**：使用概念板块近 5 日资金流入百分位数据  
  `催化剂强度 = 个股所属概念板块近5日资金净流入百分位的最高值 × 100`  
  多板块取最大值，强度 < 40 → 标记 `CAT-0`，最终分 × 0.5
- **B 档（概念指数缺失冷启动备援）**：若 Tushare 概念指数 5 日行情缺失（未及时更新） → **自动启动个股等权合成**  
  取该概念下所有成分股近 5 日涨跌幅与成交额的等权平均值，构造虚拟概念指数，据此计算资金流百分位。若合成后仍无法计算 → 降级为 AI 三档手动评估。
- **C 档（AI 三档）**：无任何概念数据 → 人工/AI 判断  
  - 高（80）：重大政策/指数纳入/重大合同  
  - 中（50）：行业性利好但弹性一般  
  - 低（30）：缺乏明确催化剂 → 自动标记 `CAT-0`

### 追高风险约束
- 催化剂强度 ≥ 70 且个股 20 日涨幅 > 15% → **强制降至 Tier 2**
- 涨幅 ≤ 15% → 保留，但禁止加仓

### 催化剂有效性追加
- 近 20 日行业内个股涨幅 > 15% 或 15 个交易日内无 ≥ 40 分新催化剂 → 降至 Tier 2  
- 指数纳入确认 → 直接赋予催化剂强度 80（免去资金流条件）

## L4 动量确认（封板判定本地化）

| # | 要素 | 标准 |
|---|------|------|
| ① | 价格动量 | 20 日涨幅在申万二级行业内排名前 30% |
| ② | 量能验证 | 近 5 日上涨日平均成交额 > 下跌日平均成交额。**数据缺失 → 跳过，不惩罚。不满足 → 动量分 ×0.7** |
| ③ | 相对强度 | 个股涨幅 > 全市场涨幅中位数 + 1% |

**加分项**：
- 近 5 日(超大+大单)净流入 / 总成交 > 15% → +5 分
- `ALPHA` 标记且行业近 5 日跌幅 < 2% → +10 分
- 同二级行业 ≥ 3 只满足①且近 5 日 ≥ 1 只 → +5 分

**特殊标记（基于日线行情本地计算，不再依赖 `limit_list` 接口）**：
- **涨停判定**：`abs(close - round(pre_close * 1.10, 2)) < 0.01` 或满足 `round(pre_close * 1.05, 2)`（ST 股），且 `high == close` → 认定为封板涨停  
- **一字板判定**：`high == low == close` 且满足涨停条件 → 认定为一字板封死  
- 连续 ≥ 2 日封板未开 → `LOCK`，开板次周重评  
- 近 20 日 ≥ 3 日封板且近 10 日 ≥ 1 日 → "突破型"  
- 封板数据缺失 → 标记跳过，不影响动量分

动量得分 = 0 → 强制降至 Tier 2。

## L5 综合评分与候选池（融合补丁二·三级漏斗 + 行业终极防御 + z2s 分布修复 + v7.4 参数对齐）

### 1. 盈利预期差标准化
- 对 Winsorized 后的"预期差原始值"（双侧分布）计算全市场 Z-Score
- 映射得分区间（扩展版，负值区间含四档梯度）：  

| Z 区间 | 标准化得分 |
|--------|------------|
| Z < -2.5 | 5 |
| -2.5 ≤ Z < -1.5 | 12 |
| -1.5 ≤ Z < -0.5 | 22 |
| -0.5 ≤ Z < 0 | 32 |
| 0 ≤ Z < 1 | 50 |
| 1 ≤ Z < 2 | 68 |
| 2 ≤ Z < 3 | 82 |
| Z ≥ 3 | 95 + (Z-3)×3（上限100） |

- **补丁三**：`COV-LOW` 标记股独立分组计算，上限锁定 1.0（即得分 50）；独立组样本 < 3 → 全部锁定 50。  
- **成分股不足处理**：  
  - 若某申万二级行业成分股 < 10 → 仅采用全市场 Z  
  - 若升至一级行业后成分股仍 < 5 → **终极防御**：该行业所有股票强制划入全市场独立池，使用 min-max 标准化，得分上限锁定 50 分。  
  - 若全市场参与计算总样本 < 10 → 全部改用 min-max 标准化。

### 2. 综合得分公式
```
EGS基础 = 预期差得分 × 20% + 催化剂强度 × 30% + 动量分 × 50%
最终分  = max(EGS基础 × 乘数积, EGS基础 × 0.3) + 加分 − 扣分
```

**乘数**：
- `ESP-Q`：×0.7
- `CAT-0`：×0.5

**加减分总览**：

| 条件 | 类型 | 量值 | 标记 |
|------|------|------|------|
| 质量存疑/数据缺失 | 乘数 | ×0.7 | ESP-Q |
| 催化剂 < 40 分 | 乘数 | ×0.5 | CAT-0 |
| 估值高危（PE>均值×3且PEG>2） | 扣分 | −15 | VAL-X |
| 行业景气不足（L1=1.5分） | 扣分 | −15 | ITF-2 |
| ITF-ADJ 触发 | 扣分 | −10 | ITF-ADJ |
| 调研过度（已冻结）/10~30日减持 | 扣分 | −10（仅减持相关） | — |
| 估值安全边际 | 加分 | +10（上限20） | — |
| 超大单净流入 > 15% | 加分 | +5 | — |

### 3. 三级漏斗流水线（补丁二核心）

**第一级漏斗（硬过滤）**：运行 L0，剔除创业板/科创板/北交所/ST/未来解禁/成交额不足 → 5000→约1200只  
**第二级漏斗（矩阵打分）**：对剩余股票执行 L1~L5 纯数学计算，按 EGS 最终分降序排列，截取 **Top 50 种子选手**（若第50名附近同分密集则扩至60只）  
**第三级漏斗（AI 联网清算）**：仅对 Top 50 进行联网搜索核查，包含：
- ① 过去 10 日大股东实际减持行为（与前置减持标记交叉验证，若有重大未标记减持则剔除）
- ② 未来 30 天解禁后的减持意愿/预披露计划
- ③ 监管立案/问询函
- ④ **行业政策风险**：检查候选股所属申万二级行业近 30 日是否存在部委限制性文件、集采、反垄断立案、专项整治等；若存在，标记 `POL-RISK`，该股**强制降级至 Tier 2 或直接淘汰**（由 AI 判断强度）

通过者进入最终候选池。

### 4. Tier 划分
- **Tier 1** = 最终分 ≥ 全市场第 75 百分位；**Tier 2** = ≥ 55 百分位  
- 准入硬条件：最终分 ≥ 50，预期差比值 > 0，催化剂强度 ≥ 40  
- 硬上限：50 只（v7.4 对齐生产脚本，原 30 只为 Phase 2 接入前的过渡值）  
- 观察留存：预期差标准化 ≥ 68 但催化剂 < 40 → 降级至 Tier 2

### 5. 分散度规则
- 单一一级行业权重 ≤ 40%  
- 单一二级行业权重 ≤ 30%（以 Top 50 为基准，30% 上限等价于最多 15 只，与 v7.3 截断值一致。百分比形式自动适应不同 top_n，更通用）  
- 超限按 EGS 降序剔除，由后续排名股票递补。
- **极端安全网**：若某二级行业在任何阶段超过 20 只进入候选池，保留脚本层 `_cap_l2` 硬截断至 15 只，作为极端情况的兜底保护。

## 实现备注（工程落地必读）

1. **财报公告日期**：所有基于单季度的财务指标，必须使用 Tushare `ann_date` 字段定位最新已公告报告期，严禁使用 `end_date`。  
2. **申万行业终极防御**：代码中必须实现"二级 < 5 → 升一级；一级仍 < 5 → 全市场独立 min-max 池"的显式逻辑。  
3. **概念指数冷启动备援**：拉取概念板块资金流前，先检测近 5 日数据完整性；若缺失则自动对成分股等权合成虚拟指数，计算涨跌幅和成交额后进行百分位排名。  
4. **封板标记本地化**：完全摒弃 `limit_list` 接口，改用 `daily` 行情中的 `close`、`pre_close`、`high`、`low` 字段按涨停公式计算，一字板等特殊形态也由本地逻辑识别。  
5. **解禁窗口前移**：数据准备阶段必须提供"未来 30 日预计解禁占流通股比例"，来自 `share_float` 或其他计划表接口，替代原来的"近 30 日解禁"。  
6. **融资/现金流数据接入**：确保 `margin`、`cashflow` 接口可用，若无权限需日志告警并跳过对应条件。  
7. **调研次数扣分永久关闭**，后续有数据源再启用。  
8. **预期差双侧分布**：`esp_raw` 须保留负值（非截断为 0），`z2s` 映射表须包含 Z < 0 的四档梯度（5/12/22/32），确保落后者有区分度。  
9. **分散度优先级**：百分比约束（一级 ≤40%、二级 ≤30%）为主规则，`_cap_l2` 硬截断为极端情况安全网，不参与常规排序。
