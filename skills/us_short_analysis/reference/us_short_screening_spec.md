## L2 预期差识别

### 2.1 盈利预期差

**一致预期方案**（分析师≥3家，60日内更新；Estimize样本≥20时与华尔街共识按6:4加权）：
```
预期差分 = mean(近两季实际EPS / max(|分析师均值预测|, $0.05) - 1)
```
单季预期差硬性上限+500%，下限-100%。分析师覆盖<3家时走替代方案。

**替代方案**（覆盖≤2家或超60日无更新）：
```
预期差分 = (本季实际EPS / 本季Guidance上限) - 1
```
若无Guidance，则与过去3年同季度EPS中位数比较。

**困境反转**：
- 一致预期EPS≤0，实际EPS>0 → 行业Z第95百分位 `REV-T`。需经营现金流>0或连续两季收入YoY>0，否则降至第75百分位且标记 `REV-T-UNCONF`。
- 近四季GAAP净利为负，但近两季营收或核心运营指标超一致预期≥10% → 行业Z第95百分位 `REV-T-OPS`。

**质量过滤**（须三项全过）：
- GAAP EPS > 一致预期×1.15（预期≤0或替代方案跳过）
- 近4季非经常性/持续经营利润 < 20%
- 经营现金流/净利 > 0.7（净利-$500万~$500万仅需现金流>0）
  - 替代通过：经营现金流/净利<0.7但近四季自由现金流为正，且递延收入YoY>20% → `ESP-Q-FCF`，L5扣5分。

不满足且无替代 → `ESP-Q`，最终分×0.7。

**修正动量**（近60日≥3家上调年度EPS≥10%）：+4分；≥3家下调≥10%：-10分 `ANL-DN`。

### 2.2 估值预期差

- 加分：行业PE近5年后30%且ROE行业前30% → +10；PB<1且ROE>10% → +10（总上限20）
  - PB无法计算（负账面价值）替代：近4季经营现金流为正且回购金额/总市值>2% → +10 `BUY-BACK`
- 扣分：PE>行业均值×2且PEG>1.5 → -10；若同时股价距52周高点5%内 → -15
- PE>行业均值×3且PEG>2 → -15 `VAL-X`
- **抱团模式豁免**：当触发`CROWD-MODE`（见L5.4），`VAL-X`扣分全面豁免。

### 2.3 资金与持仓预期差

**淘汰**：
- 内部人净卖出超市值分层阈值（>$500亿:0.1%, $100-500亿:0.2%, $50-100亿:0.3%, $10-50亿:0.5%, <$10亿:1.0%），且公司无回购，且当月卖出量 > 过去12个月月均卖出量×3。10b5-1计划豁免。
- 近5日单日跌幅>5%且收盘于最低20%区间
- 近5日借股费率 > 年化20% 且可借股票量骤降>50%：**若存在L3原始值 ≥ 2.0的主催化剂** → 不淘汰，标记 `SQUEEZE-ALERT`；**若无催化剂** → 维持淘汰。

**扣分**：
- 过去0-30日内有二次发行申请或S-3注册生效：-10
- 过度投机：Short Interest>20%且近5日均涨幅>5% 与 看涨/看跌期权未平仓比率>历史90百分位且市值<$100亿 → 双条件触发扣10分 `OVER`，单条件仅标记。

**加分**：
- 多名（≥2人）高管集中增持 → +3；若同时近90日净增持>净减持 → 再+2，标记 `BUY-SMK`。

## L3 催化剂时间表

多催化剂取最高分；次级≥40→主催化剂+10（限一次）`CAT-STACK`。

### 3.1 有效催化剂

| 类型 | 时效 | 确定性 |
|------|------|--------|
| 季报/年报、业绩预告 | 精确到天 | 2 |
| FDA PDUFA（审批待决）、重大合同签订、回购授权(>5%总股本)、并购宣告、重组/分拆、主流指数纳入 | 1-8周 | 1 |

指数纳入固定原始值3。

### 3.2 强度评分

```
原始值 = 影响广度(整体3/行业2/公司1) × 受益弹性 × 确定性 × 时间衰减 × 预期透支折扣因子
受益弹性 = 1 + 营收规模分位(前10%→1.0,10-30%→0.6,30-70%→0.3) + 业务关联度(核心占比>60%→1.0,30-60%→0.6,<30%→0.2)
时间衰减 = 1/(1+距触发天数/30)，确定性=2事件下限0.4
预期透支折扣：近20日均期权量>1万张，且事件周看涨IV-看跌IV差值>近一年80百分位 → ×0.7
催化剂强度 = 近52周历史原始值分位数（百分制），窗口<20周时用固定锚点：原始值≥2.0→80,≥1.5→60,≥1.0→40,<1.0→25
```

指数纳入：宣布至生效日涨幅>10%则强度×0.7；生效日后归零。

### 3.3 过期处置

- 兑现后涨幅>15%或15交易日无新≥40催化剂 → Tier 2；涨幅≤15%保留禁加仓
- 确定性=2事件触发后首个交易日，强度降至min(原强度,30)，强制评估止盈
- 指数纳入生效后下次重跑失效

**季报PEAD效应与冷静期**：

| 条件 | 处理 | 标记 |
|------|------|------|
| 涨幅>超预期，且均量≥3倍，且净流入>15% | 豁免抢跑限制，顺动量建仓 | `PEAD-BREAK` |
| 涨幅>超预期，且均量<3倍，且净流入<15% | Tier 2，推迟一周 | `EARN-FADE` |

EARN-FADE期满→临时催化剂=max(min(盈利预期差标准化×0.5,60),40)，时效4周。
EARN-FADE与过期处置同时触发时，优先冷静期推迟。

### 3.4 抢跑风险

行业平均涨幅 = GICS四级行业指数20日涨跌幅。
- 行业上涨且抢跑系数>1.5（无MOM-LOCK）→ 建仓半仓
- 行业下跌但个股涨≥1% → `ALPHA`
- MOM-LOCK标的豁免抢跑限制

## L4 动量确认

### 4.1 动量三要素（每项33.3分）

| # | 要素 | 标准 |
|---|------|------|
| ① | 价格动量 | 近20日涨幅行业排名前30% |
| ② | 量能验证 | 近5日机构净流入/总成交>15%（大额≥$20万）；无机构流数据则Chaikin Money Flow(20)>0.15且OBV新高 |
| ③ | 相对强度 | 涨幅 > max(标普500等权+1%, 所属行业指数+1%) |

替代路径：量能不达标但股价连续10日收于10日均线上，且20日均线斜率>0且上穿50日均线 → ②得16.6分。

修正：
- `ALPHA`且行业近5日跌幅<2% → +10分
- 同行业≥3只满足①且近5日≥1只量能突破 → +5分
- `SQUEEZE-ALERT`触发，且动量三要素至少两项满足、动量总分≥66.6 → +10分

### 4.2 异常波动（MOM-LOCK）

- 近10日出现3次以上单日涨>10%，或连续2日涨>8%且收于最高价5%内 → `MOM-LOCK`。确定性=2催化剂事件当日及次一交易日涨幅不计入，单个窗口豁免上限2天。
- **抱团模式下**：冻结阈值放宽至连续2日涨>15%。
- 触发后激活 `MOM-LOCK-TRAIL`，固定止损切换为动态跟踪止损。
- 开板次周五重评，需近5日平均日内振幅≤LOCK前20日均值1.5倍，否则维持LOCK。
- Short Interest>25%时维持突破型标记，允许持有。

动量得分=0（基础分，奖罚前）→ 强制Tier 2。

## L5 综合评分

### 5.1 季度权重校准

每季度回顾60个交易日，三因子排名与20日收益的Spearman秩相关(p>0.15为不显著)→负/不显著因子权重减半，释放权重均分其余有效因子。

默认权重：盈利预期差30%，催化剂30%，动量40%。

### 5.2 宏观断路器（脉冲式）

VIX期货近月>远月、10Y美债收益率12月高位、标普500低于200日均线。**任意两项触发**→动量权重降至20%（其余权重按比例分配），**仅生效5个交易日**。
- 第6个交易日起：
  - 若全市场个股相关性（标普500成分近20日两两相关系数中位数） > 0.8 且截面离散度萎缩 → 维持防御；
  - 若相关性从峰值回落≥0.05或连续2日下降，且有标的逆势创20日新高 → 激活 `REBEL-HERO`，动量权重恢复至40%，脉冲提前结束。

### 5.3 评分公式

盈利预期差标准化（分段线性映射）：Z<-2→5,-2~-1→20,-1~0→35,0~1→50,1~2→68,2~3→82,≥3→95+(Z-3)×3，上限100。

Z-Score=(行业Z+市值分组Z)/2；市值三分位（大盘前30%/中盘30-70%/小盘后30%），分组<10合并相邻，仍<10用5%/95%截尾min-max；行业成分<10仅用市值Z，再<10截尾min-max。

**基础分** = 盈利预期差×W1 + 催化剂×W2 + 动量×W3

**最终分** = max(基础分×乘数积, 基础分×0.3) + 加分 - min(扣分总和, 25)

| 条件 | 类型 | 量值 | 标记 |
|------|------|------|------|
| 质量存疑 | 乘数 | ×0.7 | ESP-Q |
| 现金流替代路径瑕疵 | 扣分 | -5 | ESP-Q-FCF |
| 催化剂<40 | 乘数 | ×0.5 | CAT-0 |
| 分析师下修 | 扣分 | -10 | ANL-DN |
| 过度投机双条件 | 扣分 | -10 | OVER |
| ITF 2-2.5分 | 扣分 | -15 | ITF-2 |
| ITF-ADJ | 扣分 | -10 | ITF-ADJ |
| 低吸豁免 | 扣分 | -5 | LO-EX |
| PE>均值×3且PEG>2 | 扣分 | -15 | VAL-X |
| 其他扣分项（二次发行/真空期波动等） | 扣分 | -10 | — |
| ADR且L2.1质量通过 | 扣分 | -5 | ADR |
| 分析师上修 | 加分 | +4 | — |
| 估值安全边际 | 加分 | +10(上限20) | — |
| 内部人增持 | 加分 | +3或+5 | BUY-SMK |

### 5.4 候选池、市场状态与执行

- Tier 1 ≥ 全市场第75百分位，Tier 2 ≥ 第55百分位
- 准入：最终分≥50，预期差原始值>0，催化剂≥40
- Tier 1+Tier 2合计 ≤ 30只
- 盈利预期差标准化≥68但催化剂<40 → Tier 2
- **分散度联合约束**：二级行业≤30%且一级行业≤50%，US-EGS降序最大化总分。纯度豁免：Tier 1池Z均值>1.5且分属不同三级行业→豁免一级行业上限。
- **抱团模式 `CROWD-MODE`**：标普500成分股站上50日均线比例 < 35%，且纳指或标普创近期新高时触发。退出条件：该比例回升至45%以上且维持3个交易日。触发后：
  - 豁免 `VAL-X` 扣分
  - MOM-LOCK冻结阈值放宽至连续2日涨>15%
  - 二级行业≤30%约束豁免，允许核心强势三级行业集中。
- **枯竭标记**：Tier 1连续3周<3只触发，恢复≥5只维持2周解除。财报季（1/4/7/10月第2周至次月第1周）枯竭阈值放宽为Tier 1+Tier 2<8只，EARN-FADE冷静期缩短为1个交易日。枯竭期间，Tier 1输出全市场前5名（要求最终分≥30，否则当周Tier 1输出空），标记 `FIRE-SEED`。
- **防御期**（任一触发）：①L5.2宏观断路器激活；②VIX连续5日>30；③标普500连续10日低于50日均线且斜率为负。→ Tier 1输出≤3只。**防御期与FIRE-SEED同时触发时，防御绝对优先**：FIRE-SEED输出上限压缩至≤3只，防御期内枯竭标记不触发FIRE-SEED。
- **传递规则**：跌出Tier 1 → 下周一限价单(≥前收-3%)减仓50%；止盈再入 → 催化剂较建仓快照提升≥15分；止损再入 → 催化剂提升≥20分，且重新入池后连续两周维持在Tier 1。Tier 1建仓时存储快照：日期、催化剂强度、EGS最终分、Z-Score。
