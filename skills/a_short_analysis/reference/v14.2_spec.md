## 核心规则

### Rule 1：股价零滞后 + 前复权
前复权价格，近30日除权除息须重新校验。

数据源实时穿透协议（核心补丁）：

强制实时检索： 在后续所有分析中，若用户未显式提供最新股价，系统将放弃任何内部缓存数据与历史记忆，强制在 M0 阶段调用即时联网搜索，抓取需求发出前最近一个交易日的收盘价或盘中即时价。

前复权校验： 抓取价格后，必须同步检索该股近 30 日内是否存在分红派息、送转股等除权除息事件。若存在，须自动按最新除权因子进行前复权校准，确保输入框架的价格为标准前复权价格。

两阶段交叉验证： 检索到的市场价格必须通过多源数据比对，剔除滞后、畸变或断流的离群值，彻底杜绝数据源滞后或“价格减半”等高风险长尾问题。若多源验证失败，自动触发 Rule 11 数据备用协议。

### Rule 2：价格含逻辑

### Rule 4：无死角分析

> **补丁B（复合条件完整核验）：** 含“且”的否决条件须逐条核验所有子条件，任一不满足须显式标注原因，禁止只验证部分子条件即结论。

> **跌停逃生：** 封死跌停且触及止损价→当日挂跌停卖出；未成交次交易日9:20集合竞价挂出。优先级高于所有其他止损。

### Rule 6.1：盘中量化热插拔
**触发条件：** 持仓个股或所属申万二级行业指数**同时满足**以下两项，立即执行“先减半仓”。  
1. 近15分钟内，Level-2特大单净流出速率 > 过去5天同一时段均值的2.5倍；  
2. 该时段内，个股或行业指数涨跌幅 < 同花顺全A指数 -0.5%。  

**预警前置：** 若近15分钟Level-2特大单净流出速率 > 过去5天同一时段均值的1.8倍，但尚未满足全部触发条件 → 不执行减仓，但标记“热插拔预警”，进入5分钟级监控。若后续15分钟内升级至完整触发条件 → 立即执行减半仓。

> **T+1制度分流：** 若触发标的为当日新开仓（T日买入）→无法执行当日减仓，自动标记“T+1风险待释放”，次日9:20集合竞价挂跌停价强制卖出，不受Rule 12熔断冷静期及Rule 13再入场冷静期限制。  

**已有持仓（T-1及更早买入）：** 立即执行减半仓。余下半仓：若盘中触及M3.6锁定止损位，立即清仓余下半仓；否则收盘时个股涨跌幅 ≥ 同花顺全A指数涨跌幅 − 1%→修复；未修复→计入次日核验。  
**次日核验：** 次交易日仍同时满足→余下半仓清仓；不满足→恢复正常止损管理。  

> **叠加声明：** 本规则减仓与Rule 9/Rule 12/Rule 13独立执行。若同交易日同时触发多项减仓，按各自比例独立计算后叠加。剩余仓位不足100股→全额卖出。  

> **盘后回溯：** 持仓标的盘后分析自动执行L1近似回溯（5分钟K线替代Level-2数据，阈值放宽至原值3.75倍），标记“L1近似回溯（低置信度）”写入M6.5风险提示，不作为强制减仓指令。非持仓标的不触发。

**特殊联动：** 若M2.7粗筛因IV>60%导致阻力系数被压低至1.00，则Rule 7的ATR系数强制取上限。

### Rule 7A：量化干扰豁免
- **触发：** 价格在关键支撑/压力位±0.3%内，出现连续10分钟以上“织布机走势”（每分钟振幅<0.1%且盘口挂单厚度>5日均挂单量2倍）。  
- **豁免：** 当前环境ATR止损倍数**上调0.3**。  
- **制衡：** 豁免激活期间，若出现单日大宗折价>0.5%股本，或北向单日净流出>1亿，豁免即刻失效，止损恢复原ATR标准。

### Rule 8：流动性底线+竞价校准（仅新开仓）
- 近5日均成交<5000万→不建仓；主板价差>0.15%/科创创业板>0.3%→限价单；流通市值<50亿→单只≤总资金3%  
- 建仓金额>1分钟最大承载量→强制拆分：每笔≤1分钟最大承载量，间隔≥5分钟。  
- **采集记录：** 记录5日均日成交额及昨日总成交额，传递至M6.3作为仓位计算输入。

### Rule 9：季报跳空处置
已有持仓：跳空 > max(近20日开盘缺口绝对值均值×2，2%)→30分钟K线确认；收复缺口1/3+放量→不减持；未收复→强制减仓50%。  
**Rule 9.1 候选标的：** 分析期间跳空 > max(近20日开盘缺口绝对值均值×2，2%)→暂停建仓，等30分钟K线；距收盘<30分钟顺延至次交易日开盘后确认，通过后重跑M2.0。  

> **优先级：** 若同一季报同时触发Rule 9跳空与Rule 6好数据坏反应，Rule 6 Hard Veto优先级更高。

### Rule 10：最低盈亏比
进攻期≥1.5:1，防御期≥2.0:1；防御对冲标的（①β<0.6且股息>3%；②宽基ETF；③公用事业板块）单只≤5%。  
各仓位约束独立适用，多项同时触发取最保守值。

### Rule 11：数据备用协议
M2.0关键数据缺失→盈亏比提至2.0:1。  

> **补丁C（触发前置）：** 标注数据缺失前须已用两组不同关键词各搜索一次，均无结果方可触发Rule 11并注明已尝试的搜索词。禁止首次搜索失败即触发。

### Rule 12：组合熔断
触发：连续3笔止损 / 总回撤>8% / IV单日绝对值升>5个百分点  
48h冷静期，恢复后首笔仓位≤正常50%。信号平移：熔断期内缩量二踩信号保留，解禁后首个交易日价未偏离原建仓区间上限3%可追回，首日≤1只；若解除后首个交易日开盘价偏离原区间上限超过5%，信号作废，重新走M2.0。与波动率觉醒联动取更保守值。  

> **联动竞速：** 若熔断解除日处于波动率觉醒暂停期最后24h内，平移顺延至暂停期完全结束后，建仓价按M3.7重新锚定。偏离平移3%容忍线→信号作废。

> **止损豁免：** 止损/清仓指令不受任何冷静期或熔断限制，必须无条件执行。

> **极端低仓声明：** 若熔断期内因止损豁免条款导致账户总仓位降至熔断触发前仓位的20%以下，熔断解除后恢复建仓时，首笔仓位上限调整为正常上限的25%（而非50%）。

### Rule 13：再入场协议
止损后重建仓：24h冷静期 + 新催化剂 + 重过M4 + 仓位≤原50%  
缩量二踩：回调量<原止损日60%且价未破止损位下方1%。T日卖出→T+1观察不动→T+2起方可入场。  
多重削减后<20%→放弃，不足100股→放弃。  

> **熔断叠加：** 若止损触发同时触发Rule 12熔断，Rule 13的24h冷静期计时暂停，待熔断解除后以熔断解除日为新T日重新起算。与Rule 12取截止时间较晚者（Rule 12详述）。

**进攻期打断机制：** 任意1日满足防御期条件→若前一日为进攻期先降为震荡期，次日仍满足→正式切换防御期。连续≥2日满足→进攻序列归零。若仅1日扰动次日恢复，进攻序列从暂停位置恢复。重新达成进攻条件后恢复进攻期。

**防御期降级缓冲：** 防御期条件触发时，若前一日为进攻期 → 先降级为震荡期；次日仍满足 → 正式切换防御期。IV > 90% 直接否决不适用此缓冲。

**收缩期参数适用：** 收缩期ATR参数以Rule 7为准（沿用震荡期），优先于上期环境；盈亏比、仓位上限等非ATR参数沿用上期设定。

**参数分歧处置：** 若环境切换导致仓位上限/盈亏比门槛在本分析周期内出现两种可能取值，取更保守值。

### M2.7 盈亏比硬拦截
以粗筛公式快速估算：(阻力上限×系数 − 现价) ÷ (现价 − 支撑下限×系数)。  

**粗筛专用定义：** 阻力上限=近20日最高收盘价，支撑下限=近20日最低收盘价。  

**异常值排除：** 若近20日内存在因季报/重大公告导致的单日振幅>9%且留下未回补缺口的交易日，将该日最高/最低价排除后重算区间；若排除后数据日数<10日，改用近30日区间。

**系数（IV动态分层）：**  
- 进攻期/震荡期：IV分位<30% → 1.05/0.95；30-60% → 1.03/0.93；>60% → 1.00/0.90  
- 防御期：固定1.2/0.8（不参与动态调整）

**硬拦截逻辑：**  
- 若分母≤0，或现价≤支撑下限×系数，或粗筛值 < 当前环境最低盈亏比门槛，触发硬拦截。  
- **新开仓分析：** 拦截即终止，跳至M6.7输出拒绝结论并执行M6.8隔离协议，**不触发Rule 13冷静期**。  
- **已有持仓分析：** 可继续M3精算止损止盈，但输出结论必须标注“粗筛未达标，不加仓”。

### M2.1-2.5 生态系统
上下游及同业异动；隐蔽风险：解禁/可转债强赎/汇率/质押/问询。  

**板块联动锚定（灵敏度优化）：**  
- 龙头独跌（申万二级行业成交额前三龙头，任一只跌幅>7%且放量>5日均量2.0x）→ 强制观察  
- 龙头独跌 + 行业指数跌幅>2% → 降星，建仓类型强制为“仅限低吸”  
- 尾盘复核：收盘时龙头跌幅收窄至5%以内→降星撤销，强制观察解除；收盘时行业指数跌幅仍>2%但龙头已收窄→降星撤销，观察解除  

**强制观察解除条件（双轨制）：**  
- A：龙头跌幅收窄至5%以内（收盘复核）→观察解除，允许建仓  
- B：标的现价回落至5日均线下方 →观察解除，允许低吸  
- A或B任一满足即可解除，无需两者同时满足。  

**叠加处置：** 两者独立：观察解除后须复核降星条件，仍满足→保留降星，不满足→同步撤销。

### M2.6 10日回溯
趋势线判断方向与加速度。回溯触发升级审查（三选二）：大宗折价连续扩大、融资余额下降加快、北向连续5日净流出。

## 【M3】六维度个股分析

### 3.1 基本面
行业景气、竞争格局、盈利能力趋势。  
**联动规则：** 若行业景气为逆风（营收/利润连续两季下滑且无政策催化），M5.4强制降1星；基本面结论同步写入M6.7触发条件列。

### 3.2 技术面（前复权）
压力/支撑位精算至分；RSI/MACD/均线；流动性检查及冲击成本预算。  
**止损位 → Rule 7覆写 → Rule 7A上调 → 锁定写入M3.6。禁止跳过覆写。**  
**ATR计算：** 若近14日内存在除权除息日，ATR计算窗口自动延长至20日，并在M6.5风险提示中标注“ATR含除权扰动”。

**交易方向稽核（末尾执行）：**  
- 突破型：现价必须站稳MA10上方，且当日量>5日均量1.2倍，否则强制降格为“观察”，禁止建仓。  
- 低吸型：现价必须在关键支撑位±1.5%范围内，否则暂停建仓，等待回踩确认。  
- 无论类型：现价同时低于MA5/MA10/MA20三条均线→暂停建仓，等待至少一条短期均线被收复。  
- **类型在M3.2锁定，M3.7-M6.7仅引用，不得重新判断。**

### 3.3 财报与波动率
季报数据；好数据坏反应：一致预期=Wind/东方财富分析师均值，无覆盖则=上季净利×(1+前两季同比增速均值)；管理层指引连续3季低于下限→标记指引可信度受损，进入M4升级审查。若公司无正式盈利指引区间，以上季净利×(1+前两季同比增速均值)×0.9作为下限代理值；若历史增速数据不足两季，跳过本项检查。若触发好数据坏反应→立即标记Hard Veto标志位，进入M4裁定。**补充规则：** 季报公布不足24小时，该标的暂停建仓，已有持仓维持但不得加仓；若次交易日开盘跌幅>3%且30分钟内未收复开盘价50%，立即减半仓。（补丁A节假日修正适用；豁免适用市场相对强弱修正）

### 3.3B 波动率协同审计
IV/HV>1.5→仓位额外-20%且盈亏比≥2:1  
触发后写入M6.5：IV-HV偏离，仓位已扣减。

### 3.4 分析师目标价
≥3家机构覆盖且均值目标价<现价，或≥3家近1月集体下调→M4升级审查降星。

### 3.5 持仓成本与盈亏
输出当前全部持仓的最小化结构：代码、建仓价、当前价、浮盈率、建仓日、当前止损位/止盈位。M3.5为M5.5唯一数据源，每次M6.7后自动更新。

### 3.6 止盈止损
止损=支撑位下方，经Rule 7/7A覆写锁定。精确盈亏比=(第一止盈−建仓)÷(建仓−止损)。  
**盈二备用公式：** 若无明确第二阻力位，盈二 = max(盈一 + Rule 7盈二ATR系数 × ATR(14)，建仓价 + (建仓价 − 止损价) × 2)。  
**前置校验：** M2.7已通过→方向性合格，进入精确盈亏比计算；若精确盈亏比不达标，以精确值为准强制放弃。  
**M2.7联动校验：** → 见Rule 7特殊联动条款。  
时间止损：持仓**3个交易日**浮盈未超1%→减半仓(自建仓日起21个交易日内有财报催化可豁免)。无量阴跌加速：5日均量<20日均量50%且浮亏→建仓超1.5个交易日立即减仓。

### 3.7 现价锚定与竞价校准（仅新开仓）
声明现价来源，标注低吸/突破型。  
**竞价校准三档：**  
- 偏离<2%：正常，按原计划执行  
- 2-5% + 缩量：建仓量-50% + 挂单价下移2-3%  
- >5%：建仓指令自动取消，无需重跑M0-M6  

## 【M4】强制否决检查 Hard Veto
检测到M3.3传入Hard Veto标志位→跳过升级审查，直接运行后置否决组→❌→进入M6.7禁止操作并触发Rule 13冷静期。

2. 同周同行业负面？

### 5.5B 多因子风险模型预演
